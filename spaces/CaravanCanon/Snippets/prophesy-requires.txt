If you see the goat of the Lord, but you don't see the scapegoat, Jesus has not fulfilled prophecy.  (Leviticus 16)

If you see Immanuel, but you don't see Maher Shalal Hash Baz, then Jesus has not fulfilled prophecy. (Isaiah 7-8)

If you see the anointed one, but he has not set up the abomination that causes destruction, then Jesus has not fulfilled prophecy.  (Daniel 9:26-27)

If you see the good shepherd, but you have not seen the worthless shepherd, then Jesus has not fulfilled prophecy. (Zechariah 11)
